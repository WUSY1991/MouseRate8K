# MouseRate8K — 鼠标回报率测试仪（满屏版）

合并两款参考软件的优点（逆向分析见 [ANALYSIS.md](ANALYSIS.md)）：
- **Areson Mouse Test** 的免配置 + 满屏轨迹 + 按键指示（它只能测 1K）
- **Razer Polling Rate Tester** 的 8K 精测 + 回报率曲线（它必须手选设备）

## 两个交付物
| 文件 | 说明 |
|---|---|
| `MouseRate8K.exe` | 自研满屏版（本 README 主体）|
| `Wu Mouse Test Pro 8K.exe` | **原版 Areson 的二进制补丁版**（`areson_patch.py` 生成）：修掉 1K 上限两根因（1333Hz 环窗硬上限 + 整 ms 截断），上限提至 10000Hz。**按 D 键（松开触发）切换计数模式：全报文（默认）/ 仅位移**；右下角 ver pro 1.0 / Wu 品牌；数字零填充定宽无残影。**注意：文件名即品牌名**（MFC 应用名派生自 exe 文件名，改名会连带改右下角显示） |

## 构建

```
build.bat        （MSVC 2022 x64，/MT 静态 CRT → 单 exe 无依赖）
```

产物：`MouseRate8K.exe`（约 200KB）。

## 使用

直接双击运行：**纯黑满屏界面**（铺满主显示器，Areson 式），晃动鼠标立即开始测量，自动锁定正在移动的设备。

| 元素 | 说明 |
|---|---|
| 屏幕上的彩色线 | **画线轨迹**——按住**左键**画绿线、按住**右键**画红线，画在光标真实经过的位置；只滑动不画线；**Space 清除所有轨迹** |
| 左上面板 | 当前回报率大数字 + 平均/最大/最小（半透明深色，固定位置）|
| 左下面板 | 回报率曲线（逐事件瞬时 Hz，30fps 滚动）|
| 右下面板 | 按键指示 L R M 4 5 TL TR 滚轮 + X/Y 读数 + 状态 |
| 右上下拉框 | **设备**（自动/各设备）、**量程**（125…8000/自动）、**时间窗**（100ms…30s）三个下拉框 |

### 显示语义（会话制）
- **当前**：最近 250ms 内**全部报文**数换算（零位移报文也计入，与 Razer 官方测试器同语义
  —— 8K 鼠标画极小圆也会正确显示 ~8000）；鼠标停止后 ≤250ms 归零
- **平均**：1 秒滚动**计数**平均（抗成批发报干扰）；**最大/最小/事件数**：移动时实时累计；**停止 ≥600ms 后自动全部归零**，
  下次移动从干净状态重新开始（一次连续滑动 = 一个测量会话）
- 曲线与所有数字**同口径（计数语义，抗抖动）**；时间窗可 100ms~30s 切换（细窗看包级时序，粗窗看趋势）；按 C 可手动清零一切

### 快捷键
| 键 | 功能 |
|---|---|
| Space | **只清除轨迹**（统计保留）|
| S / P | 开始（取消暂停）/ 暂停 |
| C | 清零全部（统计+曲线+轨迹）|
| L | CSV 日志开/关（`PollingRate_Log_时间戳.csv`，微秒级 dt）|
| D | 计数模式切换：**全部报文**（默认，Razer 语义）/ 仅位移（Areson 语义）；切换即清零重测 |
| T | 曲线时间窗循环（与右上"时间窗"下拉同步）：100ms → 500ms → 1s → 2s → 5s → 10s → 30s |
| 0-7 | 量程：1=125 … 7=8000，0=自动 |
| M | 最小化 |
| ESC | 退出 |
| X | （隐藏）锁定 SendInput 注入通道，自动化测试用 |
| Z | （隐藏）状态转储 debug_state.txt，调试用 |

### 设计要点（为什么准）
- 专用输入线程收 WM_INPUT，QPC 全精度时间戳，绘制/磁盘 I/O 永不阻塞测量
- 按 `hDevice` 分通道统计（多设备/触摸板事件不会互相污染间隔）
- 最大/最小用 100ms 计数桶（抗显示线程抖动），平均用 Σdt 精确值
- 环形缓冲 30 秒 × 8192 事件/秒（无 Areson 的 1333Hz 数学上限）

## 测试

```
python test_full.py 8000 3      # 用 injector.exe（C 注入器）端到端验证
python test_synthetic.py 1000 4 # 纯 Python 版（低频够用）
```
注意：SendInput 合成注入的吞吐受系统环境影响（杀毒/虚拟机忙时会被系统合并到 ~125Hz，
与被测软件无关，已用无 GUI 探针对照证实）；物理鼠标走 USB 中断路径不受此影响。
